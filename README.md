# HOS Trip Planner

THe HOS (Hours of Service) trip planner app. In this app our service is to draw the map with markers for the driver and give him the **Drivers Daily Log**

We have used the 70hrs/8days aslo the assessment labaled for fuel at least one every 1000 mile

We have used OpenRouterService and react-leaflet for the maps services as we use the overpass for searching.

The driver choose input wether by searching or pin on the map

We suggest that the break should happen after 8 consecutive hours of driving.

we used ai for the ui and some features but the full logic comes from the programmer.
